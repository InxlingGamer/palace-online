# Card artwork

Original artwork generated for this project with Codex image generation. Classic uses double-headed courts, an ornate ace of spades and red/blue backs; Simple uses single-headed portraits and SVG backs.

The Classic index font, Libre Caslon Text, is under the SIL Open Font License (OFL). Its licence file is alongside the font at `src/fonts/libre-caslon-text-OFL.txt`. Simple uses the bundled Source Serif 4 font from Fontsource.
